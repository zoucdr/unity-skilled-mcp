# 铁线前线 — 实现方案

本文回答「每个任务具体怎么做」，包括代码结构、工具调用方式、关键算法与坑。

---

## 0. 总体技术路线

| 关注点 | 决策 | 理由 |
| --- | --- | --- |
| 业务逻辑 | 写 `.cs` 文件到 `Assets/AI-Generate/RTS/Scripts/`，走 Unity 常规编译（C# 9） | `code.execute` 是 C#5 CodeDOM，无法写插值字符串、局部函数，几千行逻辑不可维护 |
| 场景装配 | `Editor/RtsSceneBuilder.cs` + `[MenuItem]`，由 `editor.execute_menu` 或 `code.execute` 触发 | 装配代码量大，放编辑器脚本可反复执行、幂等 |
| 美术 | TexGen（贴图）+ 基础几何（模型）+ UISourceGen（UI 图） | 全部程序化，换工程可复现，无外部资源依赖 |
| UI | UGUI 运行时构建（`RtsHudBuilder`）或编辑器构建，控件用真组件 | 铁律：`Button.targetGraphic` 等引用必须非空 |
| 验证 | `RtsCheats` 暴露只读/强制接口 + `gameplay.simulate_*` + 截图 + 数值断言 | Play 模式下无法人工点击，必须有可控入口 |
| 寻路 | 无 NavMesh，直线移动 + 到达散开 + 分离力 | 平地地图，成本最低且无烘焙失败风险 |

## 1. T03 美术资源实现

### 1.1 贴图（TexGen）

`texgen` 的图层语义：画布 y 向上、`uv_atlas.rect = [x0,y0,x1,y1]`、`rotation` 是单角度。
优先用简单图层组合（rect + solid/gradient + noise），避免复杂路径。

| 贴图 | 图层方案 |
| --- | --- |
| T_Ground 512² | 底：`#3E5B34` 纯色；叠：40–80 个随机椭圆/矩形 `#2E4728`/`#4E6B40`；再叠细噪点 `#00000018` |
| T_Rock 256² | 底 `#6B6F72`；叠 3–5 条斜向深色裂缝 `#3A3D40`；再叠噪点 |
| T_Metal 256² | 线性渐变 `#5A6470 → #8A94A0`；叠横向细纹 `#00000012` × 12；四角铆钉圆点 `#2A3038` |
| T_Crystal 128² | 径向渐变 `#1B4F72 → #5DADE2`；叠 2 条高光斜条 `#FFFFFF66` |

校验：文件存在、PNG 尺寸正确、`inspect` 报告非纯色（标准差 > 3）。

### 1.2 材质

统一用 Built-in `Standard`：`metallic ≤ 0.2`、`smoothness 0.25–0.4`，避免整片发白。
阵营材质 `M_TeamBlue` / `M_TeamRed` 用纯色（`_Color`），建筑细节用 `M_Metal`，地面 `M_Ground`。

### 1.3 UI 图（UISourceGen）

- 面板：`render` 生成 64×64 圆角矩形，`corner_radius 10`，border 16 → `border=[16,16,16,16]` 写入 `TextureImporter.spriteBorder`。
- 按钮：128×56，`corner_radius 8`，三态 normal/hover/pressed，border 12。
- 图标：`draw` 画 64×64 剪影（锤子、步枪、坦克、雷达）。

关键坑：`layout.json` 的 `slice` **不会**写进 Unity，必须用 `code.execute` 调 `TextureImporter` 落 `spriteBorder`，`spriteImportMode = Single`。

## 2. T04 场景实现

`RtsSceneBuilder.Build()` 步骤（幂等：先 `GameObject.Find("RTS_Root")` 存在则 `DestroyImmediate`）：

1. `EditorSceneManager.NewScene(EmptyScene, Single)` 或复用当前场景，路径 `Assets/AI-Generate/RTS/Scenes/RTS_Main.unity`。
2. 建 `RTS_Root`，子节点分组：`Environment`、`PlayerBase`、`EnemyBase`、`Neutral`、`Systems`。
3. 地面：`GameObject.CreatePrimitive(Plane)`，scale 8×1×8（Plane 默认 10 m）→ 80×80；材质 `M_Ground`，tiling 8×8。
4. 边界：4 个不可见碰撞墙（`BoxCollider`，去掉 Renderer），防止单位出界。
5. 装饰：40 个岩石（随机缩放旋转的 Cube 组合），避开基地 12 m 与矿脉 6 m。
6. 双方基地：按 GDD 坐标实例化 HQ / 3 工兵 / 2 矿脉；敌方全部挂 `Team.Red`。
7. 光照：Directional 旋转 `(38, -30, 0)`、intensity 1.1、shadowStrength 0.78；`RenderSettings.ambientMode=Flat`、`ambientLight=(0.45,0.47,0.5)`；线性雾 `(0.62,0.66,0.7)` 起点 120 终点 320。
8. 相机：`Main Camera` 位置 `(0, 34, -26)`、旋转 `(55, 0, 0)`，`RtsCamera` 组件，`orthographic=false`、`farClip=400`。
9. `Systems`：`RtsGame`、`RtsPool`、`RtsInput`、`RtsAI`、`RtsHUD` 组件。
10. 保存场景。

## 3. T05 数据与框架

### 3.1 `RtsTypes`

```csharp
public enum Team { Neutral, Blue, Red }
public enum UnitKind { Engineer, Rifleman, Tank }
public enum BuildingKind { HQ, Barracks, Turret }

public class UnitDef {
    public string Name; public int Cost; public int Supply; public float Hp;
    public float Damage; public float Range; public float Cooldown; public float Speed;
    public float BuildTime; public BuildingKind Producer;
}
```

数值表为 `static readonly Dictionary<UnitKind, UnitDef>`，唯一真源，HUD 与 AI 都读它，禁止各处硬编码。

### 3.2 `RtsGame`

- 字段：`Crystal`、`SupplyUsed`、`SupplyCap`、`Kills`、`Elapsed`、`State{Running,Paused,Won,Lost}`。
- 事件：`OnEconomyChanged`、`OnSelectionChanged`、`OnGameOver`，HUD 订阅。
- `Spend(int)` / `Refund(int)` / `CanAfford(cost, supply)`。
- 暂停：`Time.timeScale = 0/1`，同时 `AudioListener.pause`。

### 3.3 `RtsPool`

- 按 `UnitKind` 各预生成 `cap` 个（工兵 24、步兵 40、坦克 12），全部 `SetActive(false)` 挂 `RTS_Root/Pool`。
- `Spawn(kind, team, pos)`：取未激活项，`Init` 后激活；无空闲则 `Instantiate` 兜底。
- 复用避免 Instantiate 峰值卡顿；单位死亡不回池（简化：直接 Destroy，池只做开局预热）。

> 说明：真正的池化需要 `RtsUnit.Reset()` 清状态，收益在 120 单位规模下不明显，本期采用「预热 + 死亡销毁」，保留 `RtsPool` 作为生成入口统一挂材质与组件。

## 4. T06 单位与战斗

### 4.1 状态机

```
Idle ──Move──> Move ──到达──> Idle
Idle ──Attack──> Attack ──目标死/超距──> Idle
Idle ──Harvest──> ToNode ─> Harvesting ─> ToBase ─> 交付 ─> ToNode
Engineer ──Build──> MoveToSite ─> Building
任意 ──死亡──> Dead
```

`Update()` 按 `state` 分支，不做通用行为树（规模不需要）。

### 4.2 关键算法

- **散开队形**：目标点 `p`，n 个单位，第 i 个目标 `p + (cos θ, 0, sin θ) * (0.9 * sqrt(n))`，θ = i * 137.5°（黄金角，避免重叠）。
- **分离力**：每 0.1 s 遍历同队单位，`dist < 1.4` 时互相施加 `(self-other).normalized * (1.4-dist) * 2`，只在 `Idle/Move` 生效。
- **索敌**：`RtsGame.Units` 静态列表，遍历找 `dist < Range` 且 `team != mine` 的最近者。120 单位 O(n) 每 0.2 s 一次，成本可忽略。
- **伤害**：`dmg = base * Random.Range(0.9f, 1.1f)`；受击闪白用 `MaterialPropertyBlock` 改 `_Color` 0.1 s。
- **曳光**：`LineRenderer` 宽 0.06，起终点为枪口/炮口与目标胸口，`Destroy(go, 0.08f)`。

### 4.3 HP 条

不入世界 Canvas，改用 `RtsWorldOverlay` 统一绘制：每个单位一个 `Image`（红底 + 绿条），每帧 `WorldToScreenPoint` 更新位置，仅在 `hp < max || selected` 时显示。

## 5. T07 建造与生产

### 5.1 生产队列（`RtsBuilding`）

- `Queue<UnitKind>` + `progress`（秒）。`Update` 推进；完成时 `RtsPool.Spawn` 到集结点，扣人口。
- 队列最多 5 项；HUD 显示进度条与剩余数量。
- 生产时扣资源在**入队时**完成（经典 RTS 语义），取消可退款。

### 5.2 建造流程（`RtsBuildPlacer`）

1. 点击建造按钮 → `BeginPlacement(BuildingKind)`，生成半透明幽灵（材质 alpha 0.45）。
2. 每帧射线到地面，更新幽灵位置；合法性：`Physics.CheckSphere(pos, r)` 不含地面/幽灵自身，距己方建筑 ≥6、距矿 ≥4、边界内。
3. 左键确认：扣资源 → 生成 `RtsBuilding`（`isUnderConstruction=true`，HP=10%）→ 命令选中的工兵 `IssueBuild(building)`。
4. 工兵到 3 m 内后，建筑 `buildProgress` 按 `dt/buildTime` 增长，`hp = maxHp * Mathf.Lerp(0.1f, 1f, progress)`，`transform.localScale.y = Mathf.Lerp(0.1f, 1f, progress)`（以底部为轴）。
5. 完成：`isUnderConstruction=false`，人口上限 +5，加闪烁特效。

### 5.3 放置合法性可视化

幽灵材质 `_Color` 绿/红切换；同时 HUD 底部提示条显示 `LEFT CLICK TO PLACE / RIGHT CLICK TO CANCEL`。

## 6. T08 输入与相机

- 拾取：单位/建筑挂 `BoxCollider`（`isTrigger=false`）+ `RtsSelectable` 标记；`Physics.Raycast(Camera.main.ScreenPointToRay(mouse))` 取 `GetComponentInParent<RtsSelectable>()`。
- 框选：记录 `mouseDown` 屏幕点，拖拽超过 8 px 进入框选态；抬起时对每个己方单位 `WorldToScreenPoint` 判inside。
- 右键：按命中对象分派 `Attack / Harvest / Move`；空地移动。
- 相机：`Update` 中对 `targetPos`（Vector3）与 `targetHeight` 插值，避免抖动；边缘推屏只在鼠标位于 Game 视图内生效（`Input.mousePosition` 在 0..Screen.width 且窗口获得焦点）。
- 快捷键：`Input.GetKeyDown` 直接处理，不用新输入系统。

## 7. T09 AI

- 每 0.5 s `Think()`：
  - 若 `Barracks == null && Crystal >= 350` → 派工兵去建兵营。
  - 若 `Barracks 完成` → 队列不满则造步兵（资源够时优先坦克）。
  - 波次：`waveTimer += dt`，`>= 40` 且待命单位 ≥3 → 全部 `IssueAttack(playerHQ)`，重置计时。
  - 防守：玩家单位距敌 HQ < 20 → 全部 `IssueAttack(最近玩家单位)`。
- AI 采矿：3 工兵开局 `IssueHarvest(最近矿)`，矿竭自动换矿（`RtsUnit` 内已处理）。

## 8. T10 HUD

- HUD 用运行时代码构建（`RtsHudBuilder.Build()` 被 `RtsBootstrap` 在 `Awake` 调用），保证「场景文件里没有手工拖引用」——所有引用由代码 `GetComponent` 得到，避免序列化丢失。
- 每个按钮：`Image`（背景九宫格）+ `Image`（图标）+ `Text`（名称）+ `Text`（造价/快捷键）；`Button.targetGraphic = 背景 Image`，`onClick` 绑定委托。
- 文字用 `Font.CreateDynamicFontFromOSFont`？不可靠。优先 `Resources.GetBuiltinResource<Font>("Arial.ttf")`，若返回 null（新版 Unity 移除 Arial）则用 `LegacyRuntime.ttf`。文案全英文，规避中文缺字。
- 刷新策略：`RtsHUD` 每 0.1 s 刷新一次（不是每帧），减少 `Text` 重建开销；血条每帧刷新。
- 小地图：`RawImage` + 运行时 `Texture2D`（128×128），每 0.2 s 用 `SetPixels32` 画点（蓝/红/黄），`Apply(false)`。

## 9. T11 编译与装配

- 写文件 → `AssetDatabase.Refresh(ForceSynchronousImport)` → `CompilationPipeline.RequestScriptCompilation` → 等 2–4 s 查 Console。
- 断言：`console.get_logs` 中无 `error CS`、无 `NullReferenceException`。
- 装配：`RtsBootstrap.Awake()` 里 `EnsureRefs()`，缺引用直接 `Debug.LogError` 并在 HUD 显示红字，避免静默失败。

## 11. 已识别的高风险点与规避

| 风险 | 规避 |
| --- | --- |
| 脚本编译失败导致域重载、MCP 请求中断 | 每次只写 1–2 个文件；写完先 `code.probe` 探活；失败读 `console` 精确报错 |
| `editor.execute_menu` 参数不明 | 先 `schema editor.execute_menu`，失败则用 `code.execute` 反射调用静态方法 |
| 内置字体缺失 | 三级回退：`Arial.ttf` → `LegacyRuntime.ttf` → `Font.CreateDynamicFontFromOSFont("Microsoft YaHei UI")` |
| `Physics.Raycast` 命中不到单位 | 给单位加 `BoxCollider` 并把 `RtsSelectable` 放在父节点，用 `GetComponentInParent` |
| Play 模式截图黑屏 | 用 `camera.screenshot` 指定主相机；必要时 `game_view.maximize` 后再截 |
| 模拟点击坐标漂移 | 用 `Camera.WorldToScreenPoint` 反算目标屏幕坐标，不写死像素 |
| 时间缩放影响协程 | 统一用 `Time.deltaTime`，暂停时 `timeScale=0` 全部停住 |
