## 2. 任务明细

### T00 环境与能力确认

- 动作：`discover` 确认 demo 端（8008/实例号）；`groups` 统计前缀；读 `scene_build_playbook`、`unity_ugui_skill`、`unity_modeling_skill` 提示词正文。
- 完成判据：知道 texgen/uisourcegen/ugui/code/scene/gameplay 各组工具的确切名字。
- 状态：已完成。

### T01 需求文档

- 动作：把玩法、数值、UI 坐标、验收标准固化为文档。
- 完成判据：所有数值是一个确定值，不含「待定」。

### T02 任务划分与实现方案

- 动作：拆出 14 个任务及其实现路径、类设计、工具调用方式、风险对策。
- 完成判据：任何任务都能由第三人照文档直接开工。

### T03 美术资源

| 子项 | 手段 | 产物 |
| --- | --- | --- |
| 地面/岩石/金属/晶体贴图 | `texgen.*` 图层合成 → PNG | `Art/T_Ground.png` 等 4 张 |
| 材质 | `material.create` 或 `code.execute` 建 .mat | `Art/M_*.mat` 5 个 |
| UI 面板/按钮九宫格 | `uisourcegen.render` | `Art/UI/*.png` + `layout.json` |
| Sprite 导入与 border | `code.execute` 写 TextureImporter | 九宫格生效 |

- 完成判据：每张 PNG 尺寸符合规格且非纯色（用 `inspect` 或像素统计）。

### T04 场景与地图

- 动作：新建 `RTS_Main.unity`；程序化生成地面（8×8 细分 plane 或 1 个 80×80 plane）、边界墙、40 个装饰、双方基地与矿脉；配置光照与雾；保存场景。
- 工具：`scene.create` / `code.execute`（装配）/ `scene.save`。
- 完成判据：`scene.get_active` 显示 `isDirty=false`，层级含 `RTS_Root`。

### T05 数据与框架

- `RtsTypes.cs`：`Team` 枚举、`UnitKind`、`BuildingKind`、`UnitDef`/`BuildingDef` 静态数据表（与 GDD 数值一一对应）。
- `RtsGame.cs`：单例；晶体/人口/击杀/时间；`CanAfford`、`Spend`、`AddSupply`、`GameOver`、`TimeScale`。
- `RtsPool.cs`：按 `UnitKind` 预生成对象池。
- 完成判据：编译 0 error；`RtsGame.I` 在 Play 时可取到。

### T06 单位与战斗

- `RtsUnit.cs` 状态机：`Idle / Move / Attack / Harvest / Return / Build / Dead`。
- 关键方法：`IssueMove`、`IssueAttack`、`IssueHarvest`、`Tick`（每帧）、`TakeDamage`。
- 分离力：`Physics.OverlapSphere` 或维护单位列表做两两推开（≤120 个，O(n²) 可接受，每 0.1 s 一次）。
- 曳光：`LineRenderer` 存在 0.08 s，无需对象池。
- 完成判据：两个敌对单位相遇 2 s 内互相掉血。

### T07 建造与生产

- `RtsBuilding.cs`：生产队列（列表 + 计时）、建造进度（0→1，HP 递增）、炮塔自动开火。
- `RtsBuildPlacer.cs`：预览幽灵（半透明）、合法性检测（半径、距离、边界）、确认/取消。
- 完成判据：生产按钮点击后队列出现 1 项，到时单位出现在集结点。

### T08 输入与相机

- `RtsInput.cs`：射线拾取（`Physics.Raycast`，单位与建筑有 Collider）、拖拽框选（屏幕矩形 → 世界投影筛选己方单位）、右键命令分派、快捷键。
- `RtsCamera.cs`：WASD/边缘/中键拖拽/滚轮缩放/边界钳制/Home 复位。
- 完成判据：框选 3 个工兵成功；右键地面后单位移动到点击点 1.5 m 内。

### T09 敌方 AI

- `RtsAI.cs`：状态 `Opening / BuildUp / Attack / Defend`；每 0.5 s 决策一次；出兵集结点在基地外侧；波次计时器。
- 完成判据：90 s 内至少 1 个敌方步兵离开基地朝玩家方向移动。

### T10 HUD 与面板

- `RtsHUD.cs`：持有全部 UI 引用；`Refresh()` 每 0.1 s 同步资源、人口、选中信息、按钮可用性、生产进度。
- `RtsWorldOverlay.cs`：血条、选择框、命令落点、建造预览的文字提示（屏幕空间 Canvas + 世界坐标投影）。
- 完成判据：A-09；按钮 `targetGraphic` 与 `onClick` 全部非空（用反射断言）。

### T11 编译与装配

- 动作：`AssetDatabase.Refresh` → 等编译 → 读 Console；场景内组件引用补齐；保存。
- 完成判据：A-01/02/03/12。
